# Agent Bayu

Asisten AI pribadi untuk mengelola aktivitas digital: tugas, kalender, pesan, dan integrasi lain yang kamu izinkan.

## Status

Fondasi Android Kotlin + Jetpack Compose sudah tersedia. Integrasi Google Tasks, Calendar, WhatsApp, Instagram, dan backend AI akan ditambahkan bertahap.

## Build lokal

Build otomatis berjalan di GitHub Actions dengan Gradle 8.11.1, cache dependency, dan cleanup artefak APK lama.
